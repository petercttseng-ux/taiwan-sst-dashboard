# 臺灣周邊海域衛星遙測海面水溫時空分布儀表板

**Taiwan Seas Satellite SST Spatiotemporal Dashboard**

由農業部水產試驗所每日發布之「衛星海面水溫圖」PNG 影像，反演為 0.25° 網格的定量海溫資料集，並建置互動式時空分析儀表板。

🔗 **[開啟儀表板 / Open the dashboard](https://petercttseng-ux.github.io/taiwan-sst-dashboard/)**

---

## 資料集 Dataset

| 項目 | 內容 |
|---|---|
| 期間 Period | 2018-11-11 ～ 2025-10-01（2,061 日） |
| 同質基期 Baseline | 2019-06-03 ～ 2025-10-01（1,857 日） |
| 範圍 Domain | 116–128 °E, 18–32 °N |
| 解析度 Resolution | 0.25° × 0.25°（48 × 56 = 2,688 格） |
| 底層產品 Source product | GHRSST MUR L4 (JPL) / G1SST 系列每日圖檔 |
| 編碼 Encoding | `uint8` 灰階 PNG 立方，`T = value × 0.15 °C`，`255 = 無資料` |

> **本儲存庫不散布原始衛星影像**，僅存放反演後之數值資料與程式碼。

## 儀表板功能 Features

- **總覽** — KPI 卡、全域日均海溫與趨勢、各海域年均距平矩陣
- **空間分布** — 逐日水溫場／距平場，含日期滑桿與動畫播放、等溫線疊加、點選格點查看完整時間序列
- **時間序列** — 11 個海域分區的年度疊圖、全期序列、距平序列，及月平均統計
- **時緯／時經剖面** — Hovmöller 圖，呈現季節推移與暖水北抬時程
- **年月距平矩陣** — 年 × 月距平熱圖，及跨海域比較
- **海洋熱浪** — Hobday et al. (2016) 定義之事件偵測、強度分級與事件清單
- **方法與品管** — 完整方法說明、已知限制與逐項 QC 結果

分區包含：臺灣周邊全域、臺灣海峽南/北部、澎湖、東北部、東部（黑潮）、西南部（高屏）、巴士海峽、南海北部（東沙）、東海南部、西北太平洋。

## 方法 Method

1. **色階自我校正** — 逐張影像偵測色階條位置，取中位數色列建立 `RGB → 正規化位置` 查找表（最近鄰配色，歐氏距離門檻 26）。
2. **色階值域自動判定** — 以「圖上紅色等溫線必為 5 的倍數」作為內部真值，逐張檢定 `−2~30` 與 `−2~35` 兩種調色盤，取殘差較小者。自動判定率 **99.0 %**。
3. **幾何定位** — 以虛線經緯格線做最小平方擬合，建立像素 ↔ 經緯度轉換。
4. **網格聚合** — 每個 0.25° 網格取內部像素之**中位數**，對等溫線、海岸線、地名文字等疊加物具強健性。
5. **驗證** — 將反演場之等溫線重新繪製並與原圖紅色等溫線疊合比對，位置吻合。

## ⚠ 重要發現：2019-06-03 的資料不連續

反演過程中發現原始檔案庫存在**一次性的產製流程變更**，且未反映在圖面標示上：

- 色階值域自動判定結果在時間上**完全乾淨地一刀切開**：2018-11-11 ～ 2019-06-02 共 204 日全數為 `−2~30 °C`；2019-06-03 起 1,857 日全數為 `−2~35 °C`。兩段檔名同為 G1SST 系列，圖面色標刻度亦未同步更新。
- **依圖面印製刻度判讀 2019-06-03 之後的圖檔，會低估海溫約 3 ~ 5 °C。**
- 換版當日域平均出現約 **+0.5 °C 的單日跳動**（06-02 為 26.78 °C、06-03 為 27.36 °C，該時期正常升溫速率僅約 0.1 °C/日）。以同質期間氣候值為基準，前段 204 日平均距平為 **+0.56 °C**，且冷月偏高、暖月偏低，呈季節振幅被壓縮的型態 — 已非單純刻度問題，而是底層資料或處理鏈本身的差異。

**處理方式**：氣候平均值、P90 門檻與所有海洋熱浪事件一律僅以 2019-06-03 之後的同質期間計算；前段 204 日完整保留可供瀏覽，但在所有時間序列圖上以黃底標示，且不納入基期、不參與熱浪偵測與趨勢迴歸。

## 已知限制 Limitations

- **氣候基期過短**（約 6.3 年，遠短於 WMO 30 年標準）：會低估氣候值變異範圍、高估熱浪事件頻率，MHW 統計不可直接與國際文獻對照。
- **趨勢不具氣候意義**：約 6 年記錄長度不足以估計長期趨勢，受 ENSO 等年際變異主導。
- **時間覆蓋不均**：2024 年原始檔案庫僅存 5 日（2024-12-12 ～ 16），存在近一整年缺口。
- **量化誤差**：色階反推理論解析度約 ±0.15 °C；近岸窄水道格點可能受海岸線繪製影響。
- **剔除與旗標**：1 張整片單色的失敗圖檔（2020-10-13）已剔除；37 日為較粗糙的重繪版本（空間標準差 < 0.6 °C），仍保留但空間細節不可信。

本儀表板為**影像再分析視覺化工具**，非官方發布數值產品。需高精度應用請直接取用 [JPL PO.DAAC 的 MUR L4 netCDF 原始資料](https://podaac.jpl.nasa.gov/dataset/MUR-JPL-L4-GLOB-v4.1)。

## 重現流程 Reproduction

```bash
# 1) 由原始 PNG 影像反演每日網格（結果寫入 out/cube.npz 與 out/log.jsonl）
SST_ROOT=/path/to/衛星水溫圖 SST_OUT=./out python3 tools/decode_all.py

# 2) 產生儀表板資料檔（寫入 data/）
python3 tools/build_web.py

# 3) 本機預覽
python3 -m http.server 8000
```

相依套件：`numpy`、`Pillow`。前端為原生 JavaScript，無外部相依。
